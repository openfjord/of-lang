# of-lang changelog

One version number covers the whole repository: the language specification,
the `of-lang` tool and the example package. Each release is tagged `vX.Y.Z`.
Versions follow [Semantic Versioning](https://semver.org/). Before 1.0, a
minor version may break what came before.

---

## v0 — The first versions
*2026-11-17 – present*

A modeling language for software people: kinds, links, derivatives,
constraints and tests, written in YAML and checked by a command-line tool.

- **[0.1.0](v0.md#010---2026-11-17)** — the first public release: the specification, the `of-lang` tool, and a restaurant example package
