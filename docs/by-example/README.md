# The OpenFjord modeling language by example

Each page shows one thing in the language, with a short package that you can
check and test. The text is on the left and the matching code is on the right.

The folder with the name of a page is its package. To try one, run the tool on
its folder:

```console
$ of-lang check docs/by-example/hello-kind
$ of-lang test docs/by-example/defaults
```

[The reference](../../language/README.md#reference) gives the exact rules.
