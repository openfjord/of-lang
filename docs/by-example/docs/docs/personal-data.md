# Personal data

Some sorts of data need more care than others:

![](../defs/data-class.of.yaml#DataClass)

Personal data is data about a person, such as a name or an address. The law
gives each person the right to see this data and to have it deleted. Thus,
each team must know which tables hold personal data. The team gives each
such table its [DataClass](../defs/data-class.of.yaml#DataClass).
